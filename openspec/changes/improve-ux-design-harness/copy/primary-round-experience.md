# Finnish copy guidance: primary round experience

- Change: `openspec/changes/improve-ux-design-harness`
- Status: approved planning record
- Links: [UX record](../ux/primary-round-experience.md); [visual plan](../visual-design/primary-round-experience.md); [task list](../tasks.md) task 3.4
- Principle: product guidance is recorded in English; all proposed player-facing strings are Finnish.
  Use short, plain sentences that say what happened and the next available action. Do not expose API,
  browser-storage, or transport details.

## Approved terms and voice

Preserve **Väyläkaverit**, **Golf Talma Master**, **kierros**, **liittymislinkki**, **ti(i)**,
**tasoitusindeksi**, **pelitasoitustaulukko**, **pelitasoitus**, **reikäpeli**, **sivupeli**, and
**lyönti**. Use “oma” only for a participant's permitted score or settings. Say “odottaa
tallennusta” for a locally retained, unconfirmed score; do not say it is saved. Use “kierroksen
luoja” for the sole start authority.

the same wording is present as a placeholder. Announcements must pair errors with the relevant
control and use status text rather than colour alone.
